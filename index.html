Workbench

Source → repairs → DEFLATE → layout → mapping. Changing a source or repair rebuilds the byte stream. Layout and mapping reuse the current decode.

The default uses the combined v5 recipe, width 5000, stride 15001, one prefix byte, and triples. Magnitude 7 maps to 255; magnitude 4 to 60; other values to 0. Components are averaged, then each row is repeated ten times.

Pin A captures a browser-rendered reference. Change any setting and use A/B or Δ to compare. Wheel to scroll; Ctrl/⌘ + wheel to zoom. Drag to pan.

Pixel gives decoded positions and compressed-source provenance. The literal origin follows earlier copies. Field buttons toggle the selected ambiguous extra bit.

Edit recipe exposes header coordinates, excisions, NUL decisions, CR insertions and retained end bits. Copy link shares current settings; Save setup also preserves local input and dictionary files.

The reconstruction parameters are hypotheses. Original checksums and image metadata remain open. Each export includes its settings and current payload hash.
